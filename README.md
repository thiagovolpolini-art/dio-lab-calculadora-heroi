# Calculadora de Partidas Rankeadas 🎮

Projeto desenvolvido como parte de um desafio da DIO, com o objetivo de praticar os principais fundamentos da programação em Python.

O programa recebe a quantidade de vitórias e derrotas de um jogador, calcula seu saldo de partidas ranqueadas e determina seu nível, que pode variar entre Ferro e Imortal.

## Conceitos utilizados

* Variáveis
* Operadores matemáticos
* Estruturas condicionais
* Laços de repetição
* Funções
* Parâmetros e retorno de valores

## Cálculo utilizado

O saldo de partidas é calculado da seguinte forma:

`saldo de vitórias = vitórias - derrotas`

Ao final, o programa apresenta uma mensagem informando o saldo e o nível atual do jogador.
